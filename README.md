# Moksh-Website

> **Moksh Patterns** — Editorial Premium Website for High-Performing Asian Women, Leaders, Professionals, and Founders.

## 📌 Project Overview
Moksh Patterns is positioned around helping high-performing Asian women examine learned patterns, expectations, self-doubt, decision-making, identity, self-trust, and beliefs that influence how they live and lead.

- **Core Concept:** "WHO TAUGHT YOU THAT?"
- **Brand Framework:** "RECOGNISE. QUESTION. RECLAIM." | "WE IDENTIFY. WE UNDERSTAND. WE BREAK."

## 🎨 Design System
- **Primary Color:** Deep Forest Green (`#0A241A` & `#061812`)
- **Secondary Surface:** Deep Shadow Slate (`#0F3024`)
- **Light Contrast Surface:** Warm Linen Cream (`#F8F5EE`)
- **Accent Color:** Satin Antique Gold (`#C5A059`)
- **Typography:** *Cormorant Garamond* (Editorial Serif) & *Plus Jakarta Sans* (Modern Sans-Serif)

## 🚀 Local Development Setup

```bash
# Install dependencies
npm install

# Run dev server
npm run dev
```

Visit `http://localhost:3000` to view the application live.
